# Domain Docs

## 布局

采用 single-context：
- 根目录 GLOSSARY.md：项目领域术语。
- docs/adr/：架构决策记录，按 0001-<主题>.md 编号。

## 探索代码前

读取根目录 GLOSSARY.md，以及 docs/adr/ 中与当前任务相关的决策。

文件不存在时安静继续，不将缺失视为问题，也不预先建议创建。
由 domain-modeling 技能在术语或决策明确后按需创建。

## 使用领域术语

任务标题、设计建议、调试假设和测试名称使用 GLOSSARY.md
定义的术语，并遵守其中明确的同义词约束。

需要的概念尚未收录时，先确认是否误用了项目语言；
确有缺口时，记录为 domain-modeling 的后续输入。

## 决策冲突

输出与现有 ADR 冲突时，明确指出 ADR 编号、冲突内容，
以及建议重新讨论该决策的理由。
