# Triage Labels

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可交给代理独立实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提到分诊角色时，使用此表对应的 GitHub 标签。
以后调整标签命名时，更新本表的 GitHub 标签列。
