# 优先采用 QQ 官方单聊接入

本项目面向少量用户分别进行 QQ 单聊，需要语音、分条回复和主动发起交流。选择以 QQ 官方机器人作为首选接入路径，先验证目标账号的消息能力与主动发送权限，再确定具体实现；人格、记忆和主动聊天体验仍需继续讨论。

这意味着接受官方机器人身份、平台权限和消息限额，换取官方接口支持。非官方个人 QQ 账号方案可能提供不同的交互体验，但维护连续性与账号可用性存在不确定性；当前 NapCat 主仓也已显示结束声明。若官方实际能力无法满足已确认的核心体验，再重新评估替代接入路径。

依据：[QQ 官方消息规则](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)、[NapCat 当前主仓](https://github.com/NapNeko/NapCatQQ)。本决策经用户于 2026-11-12 的第一轮需求访谈确认；尚未进行账号联调。
