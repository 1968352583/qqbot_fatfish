# 用户聊天彼此隔离，管理员可查看与管理全部保留内容

本项目面向 1～5 名受邀用户，为满足项目拥有者集中查看和管理内容的要求，采用用户之间隔离、管理员具有跨用户读取和管理权限的边界。机器人生成回复时仍仅使用当前用户的私人信息；管理员可查看所有保留正文，更正或删除任意用户的长期记忆，以及删除聊天记录，原始聊天正文保持真实收发内容而不提供改写。管理员操作同样遵守保存期限和遗忘规则，删除或更正同步处理相关旧记录和记忆，避免重新提取已遗忘内容。

经用户在 2026-11-12 的 Q21、Q23 回答中确认读取边界，Q24 确认修改与删除边界；Q23 明确选择可查看全部正文，替代此前不展示他人正文的建议。
