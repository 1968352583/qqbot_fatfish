# 大肥鱼使用说明

在 QQ 单聊中直接发送文字、语音或普通图片。语音输入使用 QQ 提供的参考转写，没有转写时会请用户重说或改发文字；不会把不确定转写或图片推断自动记成事实。图片仅供当前轮理解，图片链接和文件不长期保存。

## 记忆与个人设置

| 发给机器人的内容 | 作用 |
| --- | --- |
| `/帮助` | 查看命令 |
| `/记忆`、`/记忆 2` | 分页查看自己的长期记忆 |
| `/记住 我喜欢蓝色` | 明确保存信息 |
| `/更正 记忆编号 我现在喜欢绿色` | 替换记忆，清理关联旧内容 |
| `/忘记 蓝色` | 清理含关键词的记忆、聊天及关联派生内容 |
| `/设置` | 查看实际个人偏好 |
| `/设置 主动 关` | 关闭主动闲聊，已有提醒单独管理 |
| `/设置 次数 2` | 每天最多主动开场两次 |
| `/设置 时段 9-22` | 北京时间 09:00～22:00 允许主动闲聊 |
| `/设置 间隔 3` | 主动开场最小间隔三小时 |
| `/设置 自动语音 关` | 停止偶尔自动发语音；仍可明确要求语音 |
| `/设置 语音附文 开` | 语音回复同时附上对应文字 |
| `/设置 恢复默认` | 清除个人覆盖，继承全局设置 |
| `/忙`、`我在忙` | 默认暂停主动聊天四小时；回来发消息会提前解除 |

长期记忆持续保留，原始聊天默认保留 30 天。自动记忆采用当前文字中明确表达的原文片段，区分资料、共同经历和相处习惯；原话需要前文才能理解时，最多关联两条近期文字作为依据。目前不会从语音、图片或猜测自动提取事实。所有保留记忆均可从后台查看；「角色与表达」可关闭自动积累，显式记住、更正和遗忘仍可使用。

已有记忆也支持明确的自然表达，例如「以后别叫我旧称呼了，叫我新称呼」。程序会验证当前原话及目标，实际更正后再接话；不能明确对应时不会擅自修改，可使用上表中的命令或后台处理。更正和遗忘可能同时删除一串关联记录，以及重述旧值的本轮更正请求，以避免旧事实通过上下文重新出现。新值仍需保留完整意思，不能把「我现在住上海」只记成「上海」。

每用户的聊天和记忆分别用于其自己的模型请求。管理员可以查看全部用户的保留正文、更正或删除记忆、删除聊天，不能改写原始聊天正文。更正或删除不能撤回已经发到 QQ 客户端的消息，也不能删除供应商已处理的请求。

## 提醒与主动聊天

| 示例 | 作用 |
| --- | --- |
| `/提醒 5分钟后 喝水` | 五分钟后提醒 |
| `5分钟后提醒我喝水` | 同上 |
| `/提醒 2026-12-01 08:00 出门` | 在明确的北京时间提醒；必须为未来时间 |
| `今天早上8点叫我吃饭` | 创建今天 08:00 的一次性提醒 |
| `明天下午两点半提醒我喝水` | 支持中文数字与上午、下午等时段 |
| `早上8点叫我吃饭` | 默默记为下一次早上 8 点，按人设接话 |
| `不用叫我吃饭了` | 取消能明确对应的待办约定；有多个候选时会询问 |
| `/提醒列表` | 查看近期提醒和状态 |
| `/取消提醒 提醒编号` | 取消尚未发送的提醒 |

提醒支持相对分钟、小时、完整日期时间，以及今天/明天/后天搭配明确时段的自然表达。“叫我”“喊我”“提醒我”均可识别。按照用户于 2026-11-13 确认的习惯，没说日期但明确了时刻时，采用下一次该时刻；明确说了已经过去的“今天”则不会擅自顺延。只说“8点”无法判断早晚时才简短询问，可用“早上”“明天晚上”等补充，也可以回复“取消”。未确定的时间等待 15 分钟，切换到普通话题或重启后需重新提出。每日重复提醒尚未实现。

先保存准确时间和事项，再由角色顺着当前话题接话，简短一句也可以；不要求复述日期、几点几分或事项，不额外强加打趣、叮嘱和确认流程。具体措辞随角色卡和上下文变化。用户主动询问具体时间时可以据实回答，日常聊天不显示任务编号或「已安排」回执。这是用户在实际体验后对「回应中带出日期」规则的修正。对话能看到当前用户已保存的待办约定，后续可以自然记起。到点要说的话在接下约定时一并准备并持久保存，到时无需付费模型调用；模型失败或额度不足时简短回应「好，到时候叫你。」，保留已保存的约定。相同用户、事项和时间的重复请求不会产生多个待办。

明确查询 `/提醒列表` 或打开后台时仍可查看具体时间、状态和编号。删除相关原始记录或要求忘记相关事项，会连同其约定及派生内容一起清理；仅更正用于称呼等的其他记忆时，相关预备文案会清除，避免到点说出旧信息。

后台每 15 秒检查到期提醒。默认允许迟到十分钟内补发，更旧的标为「已错过」。发送结果不确定时标为「待核对」，不会冒险自动重复发送；确认 QQ 未收到后可以重新创建。

主动聊天默认每天最多两个开场，09:00～22:00，间隔至少三小时；连续两次未回复后暂停 24 小时。次数是上限，模型可以选择这次不说话；跳过不消耗开场次数，也不增加未回复计数。每次考虑后默认至少间隔一小时再考虑，时间跨重启保留，可在后台调整。回访和新话题都可发生，关闭「允许轻松开新话题」后只回访有依据的旧话题；没有合适内容不集中补发。明确说「先不聊了」「我先休息」也会进入忙碌暂停，回来发消息提前解除。

提醒不计入主动次数。个人偏好覆盖全局默认；机器人总开关、成员停用和预算保护仍优先生效。模型收到资料与对话的实际记录时间，但话题理解和记忆提取仍可能遗漏；后台和显式命令保留为可核对、修改的入口。

## 管理员网页

打开[服务器后台](https://8.130.14.159/)；SSH 隧道建立后也可使用[备用入口](http://127.0.0.1:3210)。导航按操作目的分组：

| 分类 | 页面与用途 |
| --- | --- |
| 日常管理 | 总览、聊天与记忆、成员管理、约定提醒；处理实际对话、成员及已保存的约定 |
| 陪伴设置 | 角色与表达、主动聊天、语音与音色；调整陪伴方式和声音 |
| 运行与费用 | 用量统计、账户余额、模型与预算；查看本项目消耗、供应商余额及调用配置 |

修改设置后立即生效，正在生成的回复会中止；已发出的消息不会撤回。旧 `#members`、`#usage`、`#models` 链接继续可用；旧 `#interaction` 进入主动聊天，语音移至独立页面。

项目不限制成员总数，仍需使用管理员创建的邀请码加入。邀请码使用一次后失效，未使用时 24 小时过期。成员的主动时段、频率、忙碌暂停和语音偏好可由管理员修改；留空表示继承默认。

在「成员管理」点击某位成员的「删除」，核对姓名和说明后确认「永久删除」，会删除运行数据库中该成员的账号资料、个人偏好、全部聊天、长期记忆及提醒；后台不能撤销。其他成员不受影响，匿名历史费用继续保留。删除会取消正在生成的回复、后续尚未提交的消息及待确认约定；已经提交给 QQ 的在途请求仍可能送达，已发出的 QQ 消息不会撤回。已使用的邀请码不会恢复，再次加入需要新的有效邀请码，并从空白记录开始；删除最后一名成员也不会在重启后自动恢复旧测试账号。

当前短语音最多合成 100 字，较长回复或语音失败会发对应文字；实际时长依内容和语速而变。云服务器使用百炼 Qwen-Audio-3.1-TTS-Plus，计算在云端 API 完成，无需服务器 GPU。本机 macOS 仍可选择 Tingting 音色。

在「模型与预算」保存北京地域百炼 API Key，在「语音与音色」选择「阿里云百炼」，保存业务空间 ID 和音色 ID。默认现成音色为 `longanhuan_v3.1`。默认语气、语速、音调、音量均可调整；开启自动情绪后，模型根据当前角色和该用户的上下文生成简短语气指导，只交给语音合成，不加入聊天正文或长期记忆。关闭后仍遵循管理员设置的默认语气。

「试听与设计专属声音」可输入台词、单句语气，试听保存后的声音；试听只在后台播放，计入月度预算。填写声音描述并点击「生成新音色并试听」，满意后再点「使用这个音色」，才会替换机器人声音。也可填入已经创建、与该模型匹配的自定义音色 ID。音色设计请求会在百炼账户创建音色，未选择的音色仍保留在供应商处。初次对接请核对北京地域、业务空间、密钥和模型权限。

总预算初值 100 元/月，固定开支暂预留 30 元，费用余量 10 元，可变调用额度因此为 60 元。固定预留是待部署时调整的估算，并非已经购买服务器。达到可变额度的 80% 时后台提示，90% 暂停主动聊天和自动语音，额度不足时拒绝新付费请求；设置、后台与已有纯文字提醒仍可使用。额度按北京时间月份重置。

每次模型调用先预留估算上限，再根据返回的 token 用量结算。普通聊天模型空白或格式异常时最多恢复一次，每次均独立检查预算；主动开场格式异常则跳过，不强行补一句问候。自然记忆更正或遗忘完成后会另用一次模型调用生成不含旧值的回应；额度不足时使用简短确认。约定的自然接话与到点文案在同次生成中完成，不额外增加到时调用；网络响应过慢时八秒内转为固定确认。中断且无法确认实际用量的请求保留估算，避免漏算；费用以供应商账单为准。当前输入/输出估价为每百万 token 2/8 元，未扣缓存或闲时优惠，管理员换模型或价格变化后应同步调整。

百炼 Plus 默认按每万计费字符 1.4 元估算，汉字按两个字符预留，成功后按服务返回的字符数结算；即使音频下载失败，也保留已完成合成的费用。明确拒绝的请求归零，网络超时等结果不明的请求保留估算。音色设计当前按零元记录，但仍受预算停止保护。价格与计量最终以百炼账单为准；可在后台更新单价。

接口依据：[百炼合成 API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)、[音色设计 API](https://help.aliyun.com/zh/model-studio/voice-design-api-references)。

## 用量统计与账户余额

[任务 #7](https://github.com/1968352583/qqbot_fatfish/issues/7) 的语音统计与阿里云账户查询在[任务 #8](https://github.com/1968352583/qqbot_fatfish/issues/8) 中拆为「用量统计」和「账户余额」，并加入 DeepSeek 余额与 token 统计：

| 数据 | 含义与边界 |
| --- | --- |
| 本项目用量 | 本项目按配置单价记录的月度费用、调用次数、模型 token、语音字符和预算余量；包含后台试听与音色设计，不代表供应商实际扣款 |
| DeepSeek 余额 | 官方账户按币种返回的总可用、赠金及充值余额；各币种分开显示，不换算或跨币种相加 |
| 云账户余额 | 阿里云账户的现金余额及总可用额度，可用于多种云服务；总可用额度可能包含授信等非现金项 |
| 已购买资源包 | 阿里云账户返回的有效资源包总量、余量、单位、适用产品、地域和到期时间；不同包不能直接相加，也不默认适用于当前语音模型 |
| 百炼模型免费额度 | 当前为 `console_only`：尚未接入免费额度查询授权，只提供官方控制台入口；没有查询结果不表示额度为零 |

项目用量按北京时间月份统计，区分处理中预留、供应商回报后的结算、待核对估算和明确拒绝。已回报字符与未回报时的输入估算分别显示，不重复相加；旧记录没有采集的字符数显示「未知」，不会用当前单价反推或回填。最近 20 次语音调用可跨月份查看，记录仅包含费用、计量和结果元数据，不保存台词或音频。本机语音的计费字符不适用。该页的项目用量每 30 秒刷新一次，页面隐藏时暂停。

模型 token 来自每次供应商响应，分别显示输入、输出、总量及缓存命中、未命中、推理子集。缓存 token 属于输入，推理 token 属于输出，不再加到总量上。没有报告的字段显示未知；历史金额不反推 token。普通回复、主动开场、格式恢复、约定接话和记忆确认按实际请求逐次记录。近十四天按北京时间统计，最近二十次可跨月份查看。账本只保存计量元数据，不保存提示词或密钥。

DeepSeek 查询复用「模型与预算」中已有的 DeepSeek API Key，无需 RAM 或另一枚密钥。模型地址须为 `https://api.deepseek.com` 或其 `/v1` 路径；使用第三方网关时不会将该网关密钥发送给 DeepSeek，页面提示到对应服务商查询。余额由固定官方接口 `GET /user/balance` 获取，账户是否可调用直接使用供应商返回值。依据：[官方余额接口](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)、[模型响应计量](https://api-docs.deepseek.com/api/create-chat-completion/)。

要查看阿里云账户信息，在「账户余额 → 配置只读账户查询」中填写专用 RAM AccessKey ID、AccessKey Secret；使用临时凭据时同时填写 SecurityToken，普通 RAM 密钥则留空。百炼语音 API Key 不能替代这些凭据。所需只读权限为 `bss:DescribeAcccount`（官方名称含三个连续的 c）和 `bss:DescribeInstances`，资源范围为 `*`。凭据保存在运行服务器的受限文件中，不在页面回显；替换时填写完整密钥对，也可「清除查询凭据」。清除后停止账户查询，聊天、语音与项目用量记录继续可用。手工配置的临时凭据到期后需要更新。

账户查询缓存五分钟，可点击「刷新账户额度」主动查询。未配置时不会访问费用接口；无权、网络失败或无效响应均不会转成零余额。短时查询失败可显示最近三十分钟内的成功结果，并明确标为旧缓存；超过期限或权限被拒绝后不再显示旧值。余额和资源包分别处理失败，资源包分页未全部取回会提示只显示部分结果。没有返回资源包不等于模型免费额度为零。

任务 #7 已于 2026-11-17 部署，阿里云现金余额和资源包真实查询通过；模型免费额度仍仅提供控制台入口。各阶段验证与边界见[验证记录](validation/app.md)。
