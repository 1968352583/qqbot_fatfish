# 大肥鱼使用说明

在 QQ 单聊中直接发送文字、语音或普通图片。语音输入使用 QQ 提供的参考转写，没有转写时会请用户重说或改发文字；不会把不确定转写或图片推断自动记成事实。图片仅供当前轮理解，图片链接和文件不长期保存。

## 记忆与个人设置

| 发给机器人的内容 | 作用 |
| --- | --- |
| `/帮助` | 查看命令 |
| `/记忆`、`/记忆 2` | 分页查看自己的长期记忆 |
| `/记住 我喜欢蓝色` | 明确保存信息 |
| `/更正 记忆编号 我现在喜欢绿色` | 替换记忆，清理关联旧内容 |
| `/忘记 蓝色` | 清理含关键词的记忆、聊天及关联派生内容 |
| `/设置` | 查看实际个人偏好 |
| `/设置 主动 关` | 关闭主动闲聊，已有提醒单独管理 |
| `/设置 次数 2` | 每天最多主动开场两次 |
| `/设置 时段 9-22` | 北京时间 09:00～22:00 允许主动闲聊 |
| `/设置 间隔 3` | 主动开场最小间隔三小时 |
| `/设置 自动语音 关` | 停止偶尔自动发语音；仍可明确要求语音 |
| `/设置 语音附文 开` | 语音回复同时附上对应文字 |
| `/设置 恢复默认` | 清除个人覆盖，继承全局设置 |
| `/忙`、`我在忙` | 默认暂停主动聊天四小时；回来发消息会提前解除 |

长期记忆持续保留，原始聊天默认保留 30 天。自动记忆采用当前文字中明确表达的原文片段；目前不会从语音或图片自动提取事实。所有保留记忆均可从后台查看；更正和遗忘可能同时删除一串关联记录，以避免旧事实通过上下文重新出现。

每用户的聊天和记忆分别用于其自己的模型请求。管理员可以查看全部用户的保留正文、更正或删除记忆、删除聊天，不能改写原始聊天正文。更正或删除不能撤回已经发到 QQ 客户端的消息，也不能删除供应商已处理的请求。

## 提醒与主动聊天

| 示例 | 作用 |
| --- | --- |
| `/提醒 5分钟后 喝水` | 五分钟后提醒 |
| `5分钟后提醒我喝水` | 同上 |
| `/提醒 2026-12-01 08:00 出门` | 在明确的北京时间提醒；必须为未来时间 |
| `今天早上8点叫我吃饭` | 创建今天 08:00 的一次性提醒 |
| `明天下午两点半提醒我喝水` | 支持中文数字与上午、下午等时段 |
| `早上8点叫我吃饭` | 默默记为下一次早上 8 点，按人设接话 |
| `不用叫我吃饭了` | 取消能明确对应的待办约定；有多个候选时会询问 |
| `/提醒列表` | 查看近期提醒和状态 |
| `/取消提醒 提醒编号` | 取消尚未发送的提醒 |

提醒支持相对分钟、小时、完整日期时间，以及今天/明天/后天搭配明确时段的自然表达。“叫我”“喊我”“提醒我”均可识别。按照用户于 2026-11-13 确认的习惯，没说日期但明确了时刻时，采用下一次该时刻；明确说了已经过去的“今天”则不会擅自顺延。只说“8点”无法判断早晚时才简短询问，可用“早上”“明天晚上”等补充，也可以回复“取消”。未确定的时间等待 15 分钟，切换到普通话题或重启后需重新提出。每日重复提醒尚未实现。

先保存准确时间和事项，再由角色顺着当前话题接话，简短一句也可以；不要求复述日期、几点几分或事项，不额外强加打趣、叮嘱和确认流程。具体措辞随角色卡和上下文变化。用户主动询问具体时间时可以据实回答，日常聊天不显示任务编号或「已安排」回执。这是用户在实际体验后对「回应中带出日期」规则的修正。对话能看到当前用户已保存的待办约定，后续可以自然记起。到点要说的话在接下约定时一并准备并持久保存，到时无需付费模型调用；模型失败或额度不足时简短回应「好，到时候叫你。」，保留已保存的约定。相同用户、事项和时间的重复请求不会产生多个待办。

明确查询 `/提醒列表` 或打开后台时仍可查看具体时间、状态和编号。删除相关原始记录或要求忘记相关事项，会连同其约定及派生内容一起清理；仅更正用于称呼等的其他记忆时，相关预备文案会清除，避免到点说出旧信息。

后台每 15 秒检查到期提醒。默认允许迟到十分钟内补发，更旧的标为「已错过」。发送结果不确定时标为「待核对」，不会冒险自动重复发送；确认 QQ 未收到后可以重新创建。

主动聊天默认每天最多两个开场，09:00～22:00，间隔至少三小时；连续两次未回复后暂停 24 小时。回访和新话题都可发生，但不会积压后集中补发。提醒不计入主动次数。个人偏好覆盖全局默认；机器人总开关、成员停用和预算保护仍优先生效。

## 管理员网页

打开 [本机后台](http://127.0.0.1:3210)。页面包含总览、聊天与记忆、角色与表达、主动与语音、成员与提醒、模型与预算。修改设置后立即生效，正在生成的回复会中止；已发出的消息不会撤回。

成员最多五名。邀请码使用一次后失效，未使用时 24 小时过期。成员的主动时段、频率、忙碌暂停和语音偏好可由管理员修改；留空表示继承默认。

本机 macOS 使用 Tingting 普通话音色。当前短语音最多合成 100 字，较长回复或语音失败会发对应文字；实际时长依内容和语速而变。Linux 需要另外配置兼容的云端语音服务，尚未选定或实测。界面中的接口地址、模型和音色应使用服务商实际支持的值。

总预算初值 100 元/月，固定开支暂预留 30 元，费用余量 10 元，可变调用额度因此为 60 元。固定预留是待部署时调整的估算，并非已经购买服务器。达到可变额度的 80% 时后台提示，90% 暂停主动聊天和自动语音，额度不足时拒绝新付费请求；设置、后台与已有纯文字提醒仍可使用。额度按北京时间月份重置。

每次模型调用先预留估算上限，再根据返回的 token 用量结算。模型空白或格式异常时最多恢复一次，每次均独立检查预算。约定的自然接话与到点文案在同次生成中完成，不额外增加到时调用；网络响应过慢时八秒内转为固定确认。中断且无法确认实际用量的请求保留估算，避免漏算；费用以供应商账单为准。当前输入/输出估价为每百万 token 2/8 元，未扣缓存或闲时优惠，管理员换模型或价格变化后应同步调整。
